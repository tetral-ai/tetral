# PR Self-Check

The procedure lives in [CONTRIBUTING.md](../../../CONTRIBUTING.md) at the
repository root, so that every contributor and every coding agent reads the
same text. Read it there and follow it end to end: the five steps, then the
answer sheet, pasted into the PR description.

This file exists only so Claude Code users can reach it as `/pr-selfcheck`.
